# Topologyai

Программный комплекс для моделирования, расчёта надёжности и интеллектуальной оптимизации топологий сетей связи на базе C++ / Qt с интеграцией обученной графовой нейронной сети (GNN).

---

## 📌 О проекте

**Topologyai** предоставляет интерактивную среду для проектирования сетевых топологий, проведения аналитических расчётов вероятности связности, моделирования различных стратегий технического обслуживания узлов и интеллектуального ранжирования новых связей (рёбер) для максимального повышения надежности доставки данных.

### Ключевые возможности:
- **Интерактивный графический редактор топологии**:
  - Создание и редактирование узлов и каналов связи.
  - Настройка параметров: интенсивность отказов/восстановлений, пропускная способность, стратегии технического обслуживания.
  - Индикация собственной надёжности узлов и надёжности доставки данных (`delivery`).
- **Аналитический расчёт надёжности**:
  - Нахождение минимальных путей между терминальными вершинами (Path Finder).
  - Построение логических функций связности и ортогонализация (Logical Forms).
  - Расчёт коэффициентов готовности и вероятности безотказной работы сети.
- **Интеллектуальная оптимизация структуры сети (AI/GNN)**:
  - Интеграция с графовой нейронной сетью для предсказания прироста надёжности при добавлении связей.
  - Ранжирование потенциальных рёбер и автоматическая рекомендация наилучшей топологической модификации.

## 🧠 Модель машинного обучения (`best_model.pth`)

- В данном репозитории **отсутствуют Python-скрипты обучения** — проект предназначен для работы как законченное C++ приложение.
- В корне репозитория поставляется файл **`best_model.pth`** — предобученные веса графовой нейросети (GNN), обученной на тысячах конфигураций топологий.
- Архитектура модели учитывает признаки вершин (степень, интенсивности отказов/восстановлений, стратегию обслуживания), признаки рёбер (пропускная способность, загрузка) и глобальную связность графа.

## 🛠️ Сборка и запуск

### Требования:
- **C++17** или новее.
- **Qt 5.15+** или **Qt 6.x** (модули `Core`, `Gui`, `Widgets`, `Charts`).
- **CMake 3.16+**.
- Компилятор: **MSVC 2019+** или **MinGW 64-bit**.

### Сборка через CMake:
```bash
# Клонирование репозитория
git clone https://github.com/DanyokPenyok/Topologyai.git
cd Topologyai

# Конфигурация и сборка
mkdir build && cd build
cmake ..
cmake --build . --config Release
```

### Сборка через Qt Creator:
1. Откройте файл `CMakeLists.txt` в **Qt Creator**.
2. Выберите подходящий Kit (например, Desktop Qt 6 MinGW / MSVC).
3. Нажмите **Build** (Ctrl+B) и запустите приложение (Ctrl+R).
